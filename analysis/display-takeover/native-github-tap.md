# 点击计数反馈

在 GitHub 信息卡中轻点屏幕时，底部星标提示暂时变成居中的金色 `+1`。
连续点击显示 `+2`、`+3`……，800ms没有新的点按后恢复星标提示；恢复后下次从1开始。
数字用3倍5×7像素字形，用户名、项目名及GitHub标志沿用已验收的卡片排版。

反馈由设备GUI线程中的单调时钟和绘图提交处理，没有电脑输入或绘图循环。
保留原DRAWER_TAP条件：触摸按住时不累加，松手最多增加一次，滑动及虚拟触摸
不产生点击反馈。三击、上滑、顶边下拉和触摸所有权交接继续使用原smooth流程。

新的独立程序与安装材料使用native-github-tap命名，旧card51项冻结保留原字节。
计数使用u32并在最大值饱和；context增加feedback_ms/+176、feedback_pending/+180，
共184B。合法点按先累计，再由下一次有效单调时钟确定新反馈的起点；不会拿上一帧
的旧时间把新点按误判为已过期。恢复星形需要
成功提交对应画面后才清零序列；显示队列受阻时不改画布，期间新的点按继续累加。

此版本需要额外的小块代码空间。现有3432B主容器保留，共享helper3804be70不动；
辅助范围是原faclvgl socket worker3807a764..3807a920（444B），属于NOR95a000页。
原faclvgl入口及其引用已被卡片替换。新的独立引用审查、实时第三页只读哈希核对、
分段ELF/安装器审查均通过；主段3392B/辅助291B已安装，三页完整读回及暖启动状态
通过，不能仅用这些结果证明其他工厂代码范围也可借用。
辅助范围之外的backlight回调与JSON helper必须保留。

回退目标是原GitHub信息卡；它再通过自己的版本入口回到smooth。完整断电测试
按用户要求跳过。真实显示/手势结果与离线模拟分别记录。
